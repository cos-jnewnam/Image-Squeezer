ImageSqueezer Changelog

Changelog

Grouped by the part of the app each change touched, newest first within each group. Every entry links to the commit that made it.

Image Squeezer has no release numbers. The service worker caches against a hash of the shipped files, so an installed copy updates whenever those files actually change.

Compression and output

  • Fall back to lossless PNG when the quantizer traps

    quantize_image panics with a wasm unreachable error on some images. Encoding now catches that and produces a lossless PNG instead of failing the file outright. The fallback is larger than a quantized PNG would have been.

    70d1248

  • Target file size

    Set a size in KB and the encoder searches for a quality that lands under it, instead of holding the quality slider fixed. Quality is now also passed through to the JPEG encoder, which it previously was not.

    5edcebd

  • Quality slider

    Exposes the encoder quality from 40 to 95 rather than leaving it pinned at the default 80.

    996d906

  • Output format picker

    Choose JPG, PNG or WebP explicitly, or leave it on Auto, which encodes to several and keeps whichever comes out smallest.

    93ae8b4

Working with results

  • Share buttons removed

    The per-result Share button was dropped. Coverage for sharing files through navigator.share was inconsistent enough that the button was often present and non-functional. Copy and download cover the same ground.

    e398d08

  • Copy button

    Puts a compressed result straight on the clipboard, for pasting into a document or chat without a round trip through the downloads folder.

    96584f9

  • Before and after comparison

    A slider wipes between the original and the compressed version at full size, so a quality setting can be judged before committing to it.

    4f3262c

Installing and OS integration

  • Precache the maskable icon

    The maskable icon was referenced by the manifest but left out of the precache list, so a cold offline install could be missing it.

    815f9df

  • Open image files from the operating system

    Registers as a handler for the supported image types, so an installed copy can be set as the app that opens a JPG, PNG, WebP, HEIC and the rest.

    91e4951

  • Accept images from the system share sheet

    Share images to Image Squeezer from another app. The service worker takes the POST, parks the files in a cache, and redirects to a normal page load that picks them up.

    be7d2bf

  • In-page install button

    Surfaces installation without digging through a browser menu. Stays hidden in browsers that do not fire the install prompt event.

    f4b9d8e

Interface

  • Redesign around the squeezer artwork

    New hero layout, a light and dark theme with a toggle that remembers the choice, and a reworked results list.

    366d81c

Build and deployment

  • Build on CI instead of committing build output

    The bundled worker, the wasm codecs and the generated service worker are no longer in the repository. A GitHub Actions workflow builds them on every push to main and publishes to Pages, so the repository holds only source.

    5eab4b6

  • Initial commit

    Drop, resize and re-encode up to five images at a time, entirely in the browser, with per-image and zipped downloads and an offline-capable service worker.

    44efe4a
